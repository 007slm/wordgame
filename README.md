# 单词消消乐 (Word Match Master) 🎮📚

专为小学及初高中学生打造的**趣味单词消除与沉浸式背单词助手**。通过中英卡片配对消除、连击激励、多维考纲精讲与智能抗遗忘复习，让孩子在游戏中轻松掌握大纲核心词汇。

---

## ✨ 核心特色

1. **北京外研社小学大纲深度对标**
   - 难度阶梯严格对标**北京大兴区外研社版小学英语教材**（三年级起点：三上 M1~M10、三下 M1~M10、四年级、五六年级小升初）；
   - 覆盖中考 1600 词与高考巅峰 3500 词，支持共 75 关循序渐进闯关。

2. **多维深度研学与考点精讲 (Tab 模式)**
   - **音节自然拼读**：直观音节拆分标注（如 `he · llo`）与音标呈现；
   - **真人美式纯正发音**：单词、例句独立发音朗读；
   - **北京考纲考点与提分指南**：常考题型、避坑技巧；
   - **高频短语胶囊 & 实用情境例句**：即点即读，加深语境理解；
   - **学习档案与掌握度星级**：直观展示掌握度与答对连击次数。

3. **智能零漏词与错题动态复现机制**
   - 单元零漏词覆盖算法：必须将当前单元全部词汇至少消除配对一遍，方可满格晋级；
   - 连续答对 4 次后标记为“已毕业”，后续不再频繁重现；
   - 错误词汇与生词会自动提高复现概率，避免走马观花遗漏生词。

4. **全屏设置与自主选关**
   - 彻底去除弹窗遮罩，采用平滑全屏 Tab 切换；
   - 支持自由跨单元跳关，并配有对应的年级单元背景说明；
   - 支持一键重置关卡起点与音效开关。

5. **双端无缝支持**
   - **Web 端**：响应式极简现代 UI，自适应 PC 与手机浏览器；
   - **Android 原生端**：基于 Capacitor 打造，一键打包生成 APK。

---

## 🛠️ 技术栈

- **前端技术**：HTML5、Vanilla CSS3 (现代玻璃拟态与微交互动画)、ES6+ JavaScript
- **移动打包**：Capacitor 8 + Android Gradle
- **本地存储**：LocalStorage (游戏进度、生词本掌握度、用户昵称、个性化设置)
- **语音发音**：Web Speech API (en-US / 纯正真人发音)

## 🚀 快速开始

### 1. 本地网页运行
直接在浏览器中打开 `index.html`，或使用简易 HTTP 服务器：
```bash
# 安装并运行简易服务器
npx http-server -p 3001 -c-1
```
访问 `http://localhost:3001` 即可体验。

### 2. 构建 Android APK
需预先配置 JDK (推荐 JDK 17/21/24) 和 Android SDK：
```powershell
# 执行打包脚本
powershell -NoProfile -ExecutionPolicy Bypass -File .\build_apk.ps1
```
生成的 APK 文件将输出至 `dist-apk/wordgame-debug.apk`。
